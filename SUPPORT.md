# SUPPORT.md for dotfiles-drift

## Getting Help

- **Bug Reports:** Open an issue with the `bug` label. Include your OS, shell, and the dotfile type that failed detection.
- **Feature Requests:** Open an issue with the `enhancement` label describing the dotfile format or tool you want supported.
- **Usage Questions:** Open an issue with the `question` label.

## Community
- GitHub Discussions: Not yet available — use Issues for now.

## Priority Service Levels
| Channel | Response Time |
|---------|--------------|
| Bug reports (labeled `bug`) | Within 7 days |
| Feature requests | Triaged weekly |
| Questions | Best-effort |
